# axiell_collections_exporter

A Prometheus exporter for Axiell Collections. It reports how many object
records each collection holds, and whether each collection is **new** or a
**transfer**.

## How it works

Every `--refresh.interval` (default 2m) the exporter makes two API calls in the
background, and `/metrics` is served from memory, so scrapes are instant:

1. `?database=collname&search=all`: the collection authority file. Each
   record's `collection`, `institution` and `new_collection` fields give the
   collection's name, institution and type. `new_collection` is true when it
   reads `true`, `1` or `yes` (any case); anything else, or no value, means
   transfer.
2. `?database=collect&search=all&limit=1&facets=collection.name`: the total
   object record count plus a record count for each collection, all in one
   call. Facet buckets are joined to collname records by priref, falling back
   to name.

Collections with no records still appear, with a value of 0. If a refresh
fails, the last good values keep being served, `axiell_up` drops to 0, and
`axiell_last_refresh_success_timestamp_seconds` shows how stale the numbers
are.

## Metrics

| Metric | Labels | Meaning |
|---|---|---|
| `axiell_collection_records` | `collection`, `institution`, `type` (`new`/`transfer`) | Object records in the collection |
| `axiell_records` | `database` | All object records |
| `axiell_up` | | 1 if the last refresh succeeded |
| `axiell_last_refresh_success_timestamp_seconds` | | Time of the last successful refresh |
| `axiell_refresh_duration_seconds` | | Duration of the last refresh |
| `axiell_refresh_failures_total` | | Failed refreshes |

Useful queries: `sum by (type) (axiell_collection_records)` (totals for new
and transfer collections) and `count by (type) (axiell_collection_records)`
(number of collections of each type).

## Configuration

| Flag | Default |
|---|---|
| `--api.base-url` | `http://localhost/api/wwwopac.ashx` |
| `--api.objects-database` | `collect` |
| `--api.collections-database` | `collname` |
| `--api.collection-field` | `collection.name` |
| `--refresh.interval` | `2m` |
| `--refresh.timeout` | `90s` |
| `--web.listen-address` | `:9037` |
| `--web.telemetry-path` | `/metrics` |

Credentials are read from `AXIELL_USER` and `AXIELL_PASSWORD`. They are kept
out of the command line because wwwopac takes them as query parameters.
Without them, a server with record-level access control returns 0 for
everything.

`/healthz` returns 200 while the process is up.

## Dashboard

`grafana/axiell.json` is the "Axiell Datasets" dashboard (uid
`bdncbvl5dwttsa`), generated by `grafana/build_dashboard.py` from the currently
deployed version, which supplies the database backup panels it carries over:

    python3 grafana/build_dashboard.py path/to/current/axiell.json > grafana/axiell.json
